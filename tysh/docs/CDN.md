# CDN setup (Cloudflare free tier)

TYSHEE is built so that **no image bytes ever pass through the Next.js origin**, and so that
the HTML and static assets it does serve are cacheable at the edge. This document walks
through putting the storefront behind Cloudflare's free plan.

## What is already CDN-delivered with zero setup

| Asset | Where it comes from | Cache policy |
|---|---|---|
| Product & editorial photography | `images.unsplash.com` (imgix-backed, globally edge-cached) | Cache headers set by Unsplash, effectively immutable per URL |
| `/_next/static/*` (JS, CSS, fonts) | Your host, hashed filenames | `public, max-age=31536000, immutable` (set in `next.config.ts`) |
| Self-hosted fonts (`next/font`) | `/_next/static/media/*` | same as above |
| Static & ISR pages (home, 200 PDPs, journal) | Your host | `s-maxage` set by Next; cacheable by any CDN honouring `s-maxage` |

Every image URL is generated by `src/lib/image-url.ts` with explicit `w`, `h`, `q`,
`fit=crop` and `auto=format` parameters. Each `srcset` candidate is therefore a distinct,
deterministic, cacheable URL, and the CDN negotiates AVIF/WebP from the `Accept` header.

## Step 1 — Deploy the origin

Deploy to any Node host (Vercel, Fly, Render, a VPS). Set:

```
NEXT_PUBLIC_SITE_URL=https://your-domain.com
DATABASE_URL=libsql://…   # Turso, or any libSQL/SQLite URL
DATABASE_AUTH_TOKEN=…
AUTH_SECRET=<openssl rand -base64 48>
STRIPE_SECRET_KEY=sk_test_…
STRIPE_WEBHOOK_SECRET=whsec_…
```

## Step 2 — Put Cloudflare in front (free plan)

1. Add your domain to Cloudflare and switch its nameservers.
2. Create a proxied (orange-cloud) `CNAME`/`A` record pointing at the origin.
3. **SSL/TLS → Full (strict)**.
4. **Speed → Optimization**: enable Brotli, Early Hints, HTTP/3.
5. **Caching → Cache Rules** — add two rules:

   | Rule | Match | Action |
   |---|---|---|
   | Static assets | URI Path starts with `/_next/static/` OR `/images/` | Eligible for cache · Edge TTL: respect origin (1 year) · Browser TTL: respect origin |
   | Pages | Hostname eq your domain AND NOT (URI Path starts with `/api/` OR `/account` OR `/checkout` OR `/cart` OR `/login` OR `/register`) AND Cookie does not contain `tysh_session` | Eligible for cache · Edge TTL: respect origin |

   The second rule caches anonymous HTML at the edge while keeping signed-in and
   transactional pages dynamic. Next.js already sends `s-maxage` on static/ISR pages, and
   Cloudflare honours it.

6. **Caching → Tiered Cache**: enable Smart Tiered Caching (free) so cache misses hit one
   upper-tier data centre instead of your origin from every region.

## Step 3 (optional) — Route images through Cloudflare Image Transformations

Cloudflare can resize and re-encode images at the edge via the `/cdn-cgi/image/` URL
prefix. Enable **Images → Transformations** for the zone, then set on the origin:

```
NEXT_PUBLIC_IMAGE_CDN=cloudflare
```

The URL builder switches to:

```
/cdn-cgi/image/width=640,quality=75,format=auto,fit=cover,height=853/https://images.unsplash.com/photo-…
```

Cloudflare fetches the master once, then serves every variant from its edge. This is
useful if you later move photography to your own R2 bucket or another origin without
imgix-style parameters. With Unsplash as the origin, the default direct mode is already
optimal and needs no Cloudflare image features.

## Step 4 — Verify

```bash
curl -sI https://your-domain.com/_next/static/chunks/<any>.js | grep -iE 'cf-cache-status|cache-control'
# cf-cache-status: HIT
curl -sI https://your-domain.com/products/ines-wrap-coat | grep -iE 'cf-cache-status|cache-control'
# cf-cache-status: HIT (after first request)
```

Then re-run Lighthouse against the live URL:

```bash
npm run lighthouse -- --skip-build --origin=https://images.unsplash.com
```

## Cache invalidation

- Build assets are content-hashed: no purge needed on deploy.
- ISR pages revalidate hourly (`revalidate = 3600` on product pages); trigger an instant
  refresh with `revalidatePath()` from an admin action, and purge Cloudflare by URL or
  prefix from the dashboard/API if you need it sooner.
